개인정보처리방침

소설 작성기 (Novel Assistant) · 최종 수정일 2026년 7월 31일

요약: 이 앱은 서버가 없습니다. 작성한 원고와 입력한 API 키는 사용자 브라우저 안에만 저장되며, 개발자에게 전송되거나 수집되지 않습니다.

1. 수집하는 개인정보

없습니다. 이 앱은 회원가입이 없고, 이름·이메일·연락처 등 어떤 개인정보도 수집하지 않습니다. 운영자가 관리하는 서버나 데이터베이스가 존재하지 않습니다.

2. 원고 데이터의 저장 위치

  • 작성한 원고, 캐릭터, 세계관 등 모든 작업 내용은 브라우저의 localStorage에 저장됩니다.
  • 이 데이터는 사용자의 기기를 떠나지 않습니다.
  • 브라우저 캐시·사이트 데이터를 삭제하면 함께 사라집니다. 중요한 원고는 다운로드 버튼으로 직접 백업하시기 바랍니다.

3. Google Drive 연동 (선택 기능)

사용하지 않아도 앱의 모든 기능이 정상 동작합니다. 연동을 선택하신 경우:

  • 요청 권한은 drive.file 하나뿐입니다 — 이 앱이 만들거나 사용자가 직접 선택한 파일에만 접근합니다. 드라이브의 다른 파일은 읽을 수 없습니다.
  • 파일은 사용자 본인의 Google Drive에 저장되며, 개발자는 접근할 수 없습니다.
  • 인증은 Google이 제공하는 표준 OAuth 방식으로 처리되며, 앱은 사용자의 비밀번호를 보거나 저장하지 않습니다.
  • 연동 해제는 Google 계정 권한 관리에서 언제든 가능합니다.

4. AI 퇴고 기능 (선택 기능)

  • 사용자가 직접 발급받은 본인의 Google Gemini API 키로 동작합니다.
  • 키는 브라우저에만 저장되며, 개발자에게 전송되지 않습니다.
  • 검토를 요청하면 해당 원고가 브라우저에서 Google API 서버로 직접 전송됩니다. 중계 서버나 프록시를 거치지 않습니다.
  • 이때의 데이터 처리는 Google의 개인정보처리방침 및 Gemini API 약관을 따릅니다.
  • AI 기능을 쓰지 않으면 원고는 어떤 외부 서버로도 전송되지 않습니다.

5. 쿠키 및 분석 도구

추적 쿠키를 사용하지 않으며, 접속자 분석 도구를 설치하지 않았습니다. 광고를 게재하지 않고, 제3자에게 데이터를 제공하지 않습니다.

6. 외부 리소스

화면 표시를 위해 Google Fonts에서 웹폰트를 불러옵니다. 이 과정에서 Google에 접속 기록이 남을 수 있으며, 이는 Google의 정책을 따릅니다.

7. 주의사항

원고와 API 키가 브라우저에 저장되므로, 공용 PC나 타인의 기기에서는 사용을 권장하지 않습니다. 부득이 사용했다면 브라우저의 사이트 데이터를 삭제해 주세요.

8. 문의

이 앱은 오픈소스로 공개되어 있으며, 소스 코드에서 위 내용을 직접 확인하실 수 있습니다.
